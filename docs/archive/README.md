# Archive Directory

This directory contains historical documents and brainstorms that are no longer actively maintained but are kept for reference.

## Contents

### brainstorms/
Contains iterative brainstorm documents from the project's planning phase:
- **FILE_ORGANIZATION_BRAINSTORM.md** - Initial brainstorming on file organization
- **FILE_ORGANIZATION_BRAINSTORM_V2-V4.md** - Iterative refinements of the file organization approach
- **DRY_RUN_COMPARISON.md** - Comparison of dry run approaches
- **DRY_RUN_COMPARISON_TEMPLATE.md** - Template for dry run comparisons

These documents provide historical context for design decisions but are not part of the active documentation.
